# Stock Analysis - 个股深度分析引擎

## 一句话定位

> **从 Skill 3 输出的精选候选池（3-5 只）出发，对每只标的做基本面 + 技术面 + 大盘环境的全维度分析。输出：操作建议（进场区间 / 止损位 / 目标位 / 仓位 / 持有周期）+ 失效条件。这是整个 skill 链的最后一步 —— 给出 "买不买、怎么买" 的最终判断。**

## 核心思维模型



```
Skill 3输出的候选池（如：雅克科技/昊华科技/巨化股份/凯美特气）
    ↓
基本面扫描 —— 这只票基本面有没有硬伤？股东结构如何？
    ↓
技术面分析 —— 洗盘到位了吗？筹码结构健康吗？量价配合吗？
    ↓
大盘环境 —— 大盘对这只票影响大吗？当前大盘强/弱？
    ↓
综合判断 —— 操作建议 + 失效条件
```

## 分析框架

### Part 1：基本面扫描

目的：**排除基本面有硬伤的票，了解股东背景**。不是选基本面最好的，而是排除基本面有重大风险的。

#### 1.1 财务健康度



| 指标        | 关注什么   | 红线                  |
| --------- | ------ | ------------------- |
| 市盈率 (TTM) | 估值是否合理 | >100 或为负（亏损）需警惕     |
| 销售毛利率     | 产品竞争力  | <15% 偏低（制造业），趋势下降不好 |
| 营业收入增速    | 成长性    | 连续 2 年下降 = 衰退       |
| 归母净利润增速   | 赚钱能力   | 净利下降 + 股价上涨 = 透支    |
| 资产负债率     | 财务风险   | >70% 偏高（非金融行业）      |

**基本面硬伤**（触发任一则标注风险）：



* 连续亏损（净利为负）

* 资产负债率 > 70% + 流动比率 < 1

* 商誉占净资产 > 30%（减值风险）

* 营收连续 3 年下降

#### 1.2 十大流通股东



| 股东类型        | 含义      | 标注          |
| ----------- | ------- | ----------- |
| 北向资金 / QFII | 外资认可    | 🟢 正面       |
| 社保基金        | 长期价值认可  | 🟢 正面       |
| 国资 / 央企     | 下行有保护   | 🟢 正面       |
| 公募基金        | 机构共识    | 🟡 中性（可能抱团） |
| 自然人大量持股     | 游资 / 散户 | 🟡 关注减持风险   |
| 5% 以上股东减持   | 内部人看空   | 🔴 负面       |

#### 1.3 输出格式



```
【基本面】
  PE(TTM): 35.2 | PB: 4.1 | 毛利率: 42.3%
  营收增速: +28.5% | 净利增速: +35.2%
  资产负债率: 45.2% | 流动比率: 1.8
  
  硬伤检查: ✅无硬伤 / ⚠️{具体问题}
  
  十大股东亮点: 北向资金持仓2.1%，社保基金持仓1.5%
  股东风险: 无 / ⚠️{减持信息}
```

### Part 2：技术面分析

目的：**判断当前技术结构是否适合入场**。核心四个维度。

#### 2.1 洗盘评分（华电辽能模型，满分 14 分）

直接复用 daily\_market\_scan 中的`analyze_wash_pattern()`逻辑：



| 阶段  | 检测项                    | 分值    |
| --- | ---------------------- | ----- |
| 阶段零 | 放量砸盘但跌不动               | +2    |
| 阶段一 | 均线粘合                   | +1\~2 |
| 阶段一 | 缩量（5 日量 / 20 日量 < 0.7） | +1\~2 |
| 阶段一 | 振幅窄（<4%）               | +1    |
| 阶段一 | 横盘（20 日区间 < 10%）       | +1    |
| 阶段二 | 放量不涨                   | +1\~2 |
| 阶段二 | 冲高回落（上影线多）             | +1\~2 |
| 加分  | 底部抬高                   | +1    |

**洗盘评分解读**：



* ≥8 分：洗盘充分，启动在即 → ⭐最佳入场

* 5-7 分：洗盘进行中，可轻仓 → 🟡 关注

* <5 分：尚未进入洗盘或已经启动 → 需其他信号确认

#### 2.2 筹码结构

pywencai 直接提供：



| 指标       | 含义         | 好的信号                   |
| -------- | ---------- | ---------------------- |
| 获利比例     | 当前价以下筹码占比  | 70-95% 最健康（大部分人赚钱不急着卖） |
| 平均成本     | 流通筹码加权平均   | 现价接近平均成本 = 压力不大        |
| 集中度 90   | 90% 筹码分布范围 | 越小越集中（主力控盘）            |
| 90% 成本区间 | 主要筹码分布位置   | 现价在区间上方 = 获利充分         |
| 套牢盘      | 现价以上筹码占比   | <10% 好（上方抛压小）          |

**筹码结构解读**：



* 获利 > 90% + 集中度小 = 主力控盘，筹码锁定好

* 获利 < 50% = 大量套牢盘，上涨面临抛压

* 现价在平均成本附近 = 多空平衡区域

* 集中度 90 在缩小 = 筹码在集中（收集阶段）

#### 2.3 30 日量价分析



| 指标           | 含义        | 信号                          |
| ------------ | --------- | --------------------------- |
| 5 日 / 20 日量比 | 近期量能趋势    | <0.5 = 地量蓄势；>1.5 = 放量启动     |
| 量价配合         | 涨放量跌缩量    | ✅健康；涨缩量 = 无力；跌放量 = 出货       |
| 换手率 5 日均     | 交易活跃度     | <3%= 冷门；3-8%= 正常；>15%= 异常活跃 |
| 换手率突变        | 今日 / 5 日均 | >2 倍 = 资金异动                 |

**量价背离检测**：



* 股价创新高 + 成交量递减 = 顶背离（危险）

* 股价创新低 + 成交量递减 = 底背离（见底信号）

#### 2.4 入场信号（四重验证）

复用 daily\_market\_scan 的`calc_entry_signals()`：



| 信号                | 权重    | 含义          |
| ----------------- | ----- | ----------- |
| MACD 金叉 / 即将金叉    | +3/+2 | 动能转多        |
| VWAP60 偏离 < 3%    | +3    | 价格在 60 日成本区 |
| MA20+MA60 双线支撑    | +2    | 均线保护        |
| MA30 趋势余量 (0\~5%) | +2    | 回调到位        |

入场信号满分 10 分。≥7 分 = 强信号，4-6 分 = 一般，<4 分 = 无信号。

#### 2.5 技术面输出格式



```
【技术面】
  洗盘评分: 8/14 (均线粘合+缩量+冲高回落) → ⭐洗盘充分
  入场信号: 7/10 (MACD即将金叉+VWAP区间+MA支撑)
  
  筹码: 获利92.3% | 套牢7.7% | 平均成本133.0 | 集中度90=15.8%
       → 筹码锁定好，上方抛压小
  
  量价: 5日量/20日量=0.65(缩量中) | 换手率3.2%(正常)
       → 缩量蓄势阶段，待放量确认
```

#### 2.6 趋势追踪模块（产业催化驱动型）

**适用场景**：Skill 1-3 已确认产业逻辑的趋势股。当洗盘模型评分低但股价已在多头排列中时，切换到此模块。

**路由逻辑**：



```
MA5 > MA10 > MA20 且 现价 > MA5？ → 趋势追踪模块
否则 → 洗盘抄底模块（2.1-2.4）
```

**前提条件**（硬性，缺一不可）：



1. 产业逻辑已被 Skill 1-3 确认

2. 多头排列或趋势初期（MA5 领先）

##### 信号 A：回踩确认型（低风险）



| 条件   | 判断标准                      |
| ---- | ------------------------- |
| 回踩目标 | 价格接近 MA5/MA10/MA20（±1-2%） |
| 回踩缩量 | 回踩期间 5 日量 / 前 10 日量 < 0.7 |
| 反弹确认 | 出现阳线 + 当日量 > 5 日均量 1.2 倍  |
| 买点   | 反弹确认日                     |
| 止损   | 回踩低点下方 或 支撑均线下方           |

##### 信号 B：突破确认型（中风险）



| 条件   | 判断标准              |
| ---- | ----------------- |
| 突破位  | 收盘创近 20 日新高       |
| 放量确认 | 当日量 > 5 日均量 1.5 倍 |
| 排除涨停 | 涨停日不算有效信号（不追涨停）   |
| 买点   | 突破日收盘 或 次日回踩突破位确认 |
| 止损   | 突破位下方（前高变支撑）      |

##### 仓位控制（偏离 MA20 分档）



| 偏离 MA20 | 状态  | 仓位上限   | 止损均线 |
| ------- | --- | ------ | ---- |
| 0-10%   | 回踩区 | 7 成    | MA20 |
| 10-20%  | 趋势中 | 5 成    | MA10 |
| 20-40%  | 加速段 | 3 成    | MA5  |
| >40%    | 过热  | **不追** | —    |

##### 趋势追踪风控红线



* VWAP60 偏离 > 40% → 过热不追

* 连续 3 日放量 + 涨幅递减 → 顶部分配特征

* 获利比例 < 80% → 筹码不稳定

* 无 Skill 1-3 产业催化 → 不适用趋势模块

* 当日涨停 → 不追，等次日确认

##### 趋势输出格式



```
【趋势追踪】★多头排列 / ☆趋势初期
  偏离MA20: +X.X% → 仓位上限: X成
  
  [回踩信号] 接近MAxx | 缩量0.6x | 反弹确认: 是/否
  [突破信号] 突破XX.X | 放量1.8x
  
  进场区间: XX.X ~ XX.X (回踩MAxx / 突破位)
  止损: XX.X (MAxx下方)
  仓位: X成 (偏离度限制)
  前提: ← Skill 1-3确认 {催化名称}
```

### Part 3：大盘环境

目的：**判断大盘对个股操作的影响程度**。

#### 3.1 大盘敏感度

计算个股近 20 日日收益率 vs 上证指数日收益率的**Pearson 相关系数**：



| 相关系数     | 大盘敏感度 | 含义                |
| -------- | ----- | ----------------- |
| >0.7     | 高     | 大盘跌它大概率跟跌，操作必须看大盘 |
| 0.3\~0.7 | 中     | 有一定联动但不完全跟随       |
| <0.3     | 低     | 独立走势，主要看个股自身逻辑    |

#### 3.2 当前大盘状态



| 指标         | 看什么                 |
| ---------- | ------------------- |
| 上证近 5 日趋势  | 涨 / 跌 / 震荡          |
| 上证 vs MA20 | 在上方 = 多头环境，在下方 = 空头 |
| 上证 vs MA60 | 中期趋势方向              |

#### 3.3 大盘环境对操作的影响



| 大盘敏感度 | 大盘强  | 大盘弱            |
| ----- | ---- | -------------- |
| 高     | 正常操作 | ⚠️仓位减半 / 等大盘企稳 |
| 中     | 正常操作 | 适当谨慎           |
| 低     | 正常操作 | 正常操作（独立逻辑）     |

#### 3.4 输出格式



```
【大盘环境】
  上证指数: 3245.6 | 近5日+1.2% | 站上MA20(3220) | MA60下方(3310)
  大盘状态: 短期偏强，中期偏弱
  
  个股相关性: 0.45(中等) 
  → 大盘有一定影响但不主导，操作可正常进行
```

## 综合判断框架

### 评分逻辑（LLM 综合打分，非简单加减）

LLM 在看完三部分数据后，按以下逻辑做综合判断：

**一票否决（触发任一则 → 不参与）**：



* 基本面硬伤（连续亏损 / 负债过高）

* 大盘敏感度高 + 大盘明确走弱

* 获利比例 < 40%（上方套牢盘太重）—— 洗盘模式

* 获利比例 < 80%—— 趋势追踪模式

* 5% 以上股东正在减持

* 趋势追踪模式下偏离 MA20>40%（过热不追）

**看多信号叠加**：



* 洗盘评分≥8 + 入场信号≥7 → 强烈看多（洗盘模式）

* 多头排列 + 回踩确认 + 产业催化 → 趋势回踩买入

* 多头排列 + 放量突破 + 产业催化 → 趋势突破跟进

* 筹码集中 + 北向 / 社保持仓 → 中长期看多

* 缩量蓄势 + MACD 即将金叉 → 短期启动信号

### 操作建议模板



```
【操作建议】
  结论: ✅买入 / 🟡轻仓试探 / ⚠️观察等待 / ❌不参与

  进场区间: XX.X ~ XX.X（依据：MA10/回踩支撑位）
  止损位: XX.X（依据：前低/支撑破位）
  风险%: (进场价-止损)/进场价 = X.X%
  第一目标: XX.X（依据：MA20/前高/压力位）
  第二目标: XX.X（依据：MA60/历史密集区）
  
  仓位建议: X成
  持有周期: X-X个交易日
  
  买入逻辑（一句话）: {为什么现在可以买}
```

### 失效 / 退出条件

**每只标的必须给出明确的退出条件**：



```
【失效条件】（触发任一立即离场）
  1. 价格跌破{止损位}
  2. {具体的量价失效信号}
  3. {基本面/催化层面的失效}
```

## 注意事项



1. **数据先于判断**：必须先跑脚本拿到数据，再做判断。不可用 LLM 记忆中的 "印象" 替代实际数据

2. **止损是红线**：每只标的必须有明确止损位，风险 % 超过 10% 的不建议参与

3. **仓位与风险成反比**：风险 % 越大→仓位越轻（风险 8%→半仓以下，风险 5%→7 成以下）

4. **基本面是底线不是加分项**：基本面好不加分，基本面差一票否决

5. **技术面决定时机**：产业逻辑对（Skill 2/3 已验证），技术面决定 "什么时候买"

6. **大盘环境是风控**：大盘弱 + 敏感度高 = 必须降低仓位

7. **不是每只都要买**：即使通过了 Skill 3 的筛选，技术面不到位也可以 "观察等待"

8. **洗盘完成 + 放量启动 = 最佳时机**：这是核心交易信号

9. **LLM 代码不可信**：所有数据必须来自脚本 /pywencai 返回
