# Stock Pool - 方向验证与股池筛选引擎

## 一句话定位

> **从 Skill 2 给出的传导节点出发，验证方向热度、构建可交易股池、用硬性条件排除不合格标的。输出：精选候选池（3-5 只）供 Skill 4 做量价技术分析。本 skill 不做 "能不能买" 的判断，只做筛选和排除。**

## 核心思维模型



```
Skill 2输出的传导节点（如：半导体特种气体/靶材 ── 出货量跟涨）
    ↓
Step 1：方向热度判断 —— 这个方向整体传导到哪了？值不值得进一步看？
    ↓
Step 2：股池构建 —— 三层搜索 + 纯正度验证 + 可交易性筛选
    ↓
Step 3：排除过滤 —— 用硬性条件排除（过热/催化衰竭/公司证伪/减持）
    ↓
输出：精选候选池（3-5只）→ 送Skill 4做技术面分析
```

**本 skill 的定位**：漏斗式筛选器。从几十只候选缩小到 3-5 只精选，交给 Skill 4 做最终的量价 / 进场 / 止损判断。

## 工作流程

### 输入

来自 Skill 2 的传导节点，格式：



```
{节点名称} ── {传导机制}
状态: ⭐尚未传导 / 🟡正在传导
```

例如：



* "半导体特种气体 / 靶材 ── 出货量跟涨"

* "铝电容 ── AI 服务器单机用量 5-8x"

* "电极箔 ── 铝电容量增的上游材料"

### Step 1：方向热度判断

核心问题：**"这个方向整体传导到哪了？值不值得继续看？"**

#### 方法：用 pywencai 批量查询方向内代表公司的近期涨幅



```
import pywencai

# 推荐用代码批量查（用名称逐个查可能返回None）
result = pywencai.get(
    query='股票代码是002409或股票代码是600378或股票代码是300346 近5日涨跌幅 近20日涨跌幅',
    loop=True
)
```

#### 分层标准



| 状态          | 近 5 日涨幅   | 近 20 日涨幅  | 方向级结论                 |
| ----------- | --------- | --------- | --------------------- |
| **全线过热** 🔴 | 龙头 > 20%  | 龙头 > 50%  | **直接 pass，不进 Step 2** |
| **加速期** 🟡  | 龙头 10-20% | 龙头 20-50% | 继续，但重点看二线 / 滞后标的      |
| **启动期** 🟢  | 龙头 5-10%  | 10-20%    | 最佳，全面筛选               |
| **尚未启动** ⭐  | <5%       | <10%      | 继续，但标注 "可能需等催化触发"     |

#### 方向级快速判断



* 龙头过热 + 二线尚未 = **扩散阶段**（重点看二线）

* 全线过热 = **pass**（不参与，直接结束）

* 龙头启动 + 全线未动 = **初期**（优先龙头）

* 全线未动 = **等待催化**（标注观察）

> ⚠️ 
>
> **全线过热直接结束**
>
> ：如果 Step 1 判断为全线过热，输出 "方向已过热，暂不参与"，不需要进 Step 2/3。



***

### Step 2：股池构建

核心问题：**"这个方向有哪些可交易的票？谁最纯正？"**

#### 2.1 候选标的搜索（三层搜索）



```
import pywencai

# Layer 1: 产业链搜索（带相关系数，最精确）
result = pywencai.get(query='半导体特种气体产业链上市公司', loop=True)
# 返回: 代码/简称/相关产品/相关系数(0-100%)

# Layer 2: 主营业务搜索
result = pywencai.get(query='主营业务包含电子气体 或 主营业务包含特种气体', loop=True)

# Layer 3: 概念标签搜索
result = pywencai.get(query='所属概念包含电子特气', loop=True)
```

也可直接用 `chain_search.py`：



```
python3 /Users/bytedance/Documents/stock/chain-mapping/scripts/chain_search.py \
  --all --concept "电子特气" --business "电子气体" "特种气体" \
  --chain "半导体特种气体产业链上市公司"
```

#### 2.2 纯正度验证

对每个候选标的，验证其与目标方向的实际相关度：

**数据来源**：



* pywencai 产业链搜索返回的 "相关系数"（0-100%）

* pywencai 主营构成查询：`pywencai.get(query='XXX 主营业务构成', loop=True)`

**纯正度判断标准**：



| 纯正度            | 标准                    | 处理      |
| -------------- | --------------------- | ------- |
| **高** (>60%)   | 目标业务占营收主导，或相关系数 > 60% | ✅ 入池    |
| **中** (30-60%) | 目标业务是重要板块之一           | ✅ 入池，标注 |
| **低** (<30%)   | 目标业务只是小业务             | ❌ 排除    |

**纯正度 < 30% 的标的直接排除，不入池。**

#### 2.3 可交易性筛选

**用户只能交易沪深主板**：



* 沪主板：600、601、603、605

* 深主板：000、001、002、003

* 创业板（300/301）、科创板（688/689）、北交所（8/4 开头）**不可买**

不可交易的标的标注 `[不可交易]` 但保留作为方向参考（如龙头在创业板，说明方向存在但无法参与）。

#### 2.4 角色分配



| 角色       | 含义              | 特征              |
| -------- | --------------- | --------------- |
| **龙头**   | 方向最纯正 + 市场认知度最高 | 相关系数最高 / 最先异动   |
| **龙二**   | 第二梯队            | 纯正度高但市值 / 知名度稍逊 |
| **弹性标的** | 市值小 + 纯正度尚可     | 容易暴涨暴跌          |
| **上游材料** | 方向的上游供给环节       | 涨幅通常滞后          |



***

### Step 3：排除过滤

核心问题：**"哪些票虽然在池子里，但不应该送去做技术分析？"**

#### 排除逻辑的核心原则

**只做硬性排除（有数据支撑），不做主观的 "能不能买" 判断。**

排除的目的是去掉 "明显不值得花时间做 Skill 4 分析" 的标的。没被排除的全部送 Skill 4。

#### 排除条件（按优先级）



| # | 排除条件        | 数据来源                      | 判断标准                           |
| - | ----------- | ------------------------- | ------------------------------ |
| 1 | **过热排除**    | pywencai 近 5 日 / 近 20 日涨幅 | 近 5 日 > 25% **且** 近 20 日 > 50% |
| 2 | **催化衰竭排除**  | pywencai"涨停原因" 时间线        | 最近异动距今 > 7 个交易日 且 无新催化         |
| 3 | **公司证伪排除**  | "涨停原因" 详情中的公司原因           | 公司明确澄清 "无业绩 / 试产 / 不影响"        |
| 4 | **大股东减持排除** | "涨停原因" 详情 或 公告            | 5% 以上股东正在减持                    |

#### 关于催化数据的获取



```
# 核心查询：获取催化事件时间线
result = pywencai.get(query='XXX 涨停原因', loop=True)
# 返回dict，关键字段：
# - '涨停原因类别': DataFrame(date, keyword, list[行业原因+公司原因])
# - 'txt1': 文本摘要
```

**重要：此查询只对 "有过异动（涨停 / 大涨）的票" 返回结构化数据。**

对于不同情况的标的：



| 标的状态            | 催化数据          | 处理方式                |
| --------------- | ------------- | ------------------- |
| 近期有异动（涨停 / 大涨）  | `涨停原因`返回完整时间线 | 用时间线做排除判断           |
| 近期没有异动（缓涨 / 没动） | `涨停原因`无数据     | **不排除，直接送 Skill 4** |

> 逻辑：没动的票不需要做催化排除 —— 它们本身就是 "还没被市场定价" 的候选，Skill 4 会从技术面判断是否有参与价值。

#### 排除判断示例



```
和远气体(002971)：
  近5日+27.7%, 近20日+94.2% → 触发"过热排除"
  涨停原因详情：公司多次澄清"试产阶段，2-3年内无业绩" → 触发"证伪排除"
  涨停原因详情：5%以上股东减持 → 触发"减持排除"
  → ❌ 排除（3条命中）

雅克科技(002409)：
  近5日+11.4%, 近20日+32.2% → 未触发过热（不满足双条件）
  涨停原因：6/10、6/11连续异动，催化密集 → 未触发衰竭
  无公司证伪/减持 → 未触发
  → ✅ 进入Skill 4

至纯科技(603690)：
  近5日+3%, 近20日-2.8% → 未过热
  涨停原因：无数据（近期无异动）→ 不排除
  → ✅ 进入Skill 4（但标注"近期无催化，需Skill 4确认技术面是否有信号"）
```

## 注意事项



1. **纯正度是第一筛选条件**：<30% 直接排除，不浪费 Skill 4 的分析时间

2. **排除要有数据支撑**：每个排除决定都要标明来源（涨幅数据 / 公告内容 / 催化时间线）

3. **没动的票不排除**：缺乏催化数据≠排除理由，交给 Skill 4 从技术面判断

4. **方向过热直接 pass**：Step 1 判断全线过热就结束，不进 Step 2/3

5. **不硬凑**：如果筛完可交易的纯正标的 < 2 只，坦诚说 "A 股无合适标的"

6. **LLM 代码不可信**：所有股票代码必须来自 pywencai 返回

7. **龙头在创业板≠放弃**：如果龙头不可交易但二线可交易，标注清楚即可

8. **本 skill 不给买卖建议**：只负责筛选，"能不能买" 留给 Skill 4

9. **排除条件宁严勿松**：宁可多送一只给 Skill 4，也不要误排除。只有非常明确的信号才排除
